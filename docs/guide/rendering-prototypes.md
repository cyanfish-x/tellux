# 渲染管线边界实验

以下 Sandcastle 案例用于验证现有 Three.js、Takram 和 Spark 的接入边界，包括三个初始原型和后续 A1–A3 实验。它们不是正式公开 API，也不代表完整透明管线已经实现。均使用 WebGL，不需要地图 token。

| 案例 | 验证内容 |
| --- | --- |
| [分阶段绘制](../../sandcastle.html?example=rendering-stages) | 青色透明柱跨越地平线，白墙遮挡其下部；切换原始场景、大气前、大气后三种位置 |
| [高斯空气透视](../../sandcastle.html?example=rendering-splat-atmosphere) | Spark Butterfly 按自身栅格深度调用 Takram 散射函数；开关自身空气透视并改变观察距离 |
| [云与透明穿插](../../sandcastle.html?example=rendering-cloud-transparency) | 同高不透明柱、透明柱和交叉透明面与真实体积云对照；暴露前后合成的局限 |
| [A2 折射介质路径](../../sandcastle.html?example=rendering-refraction-medium) | 原生 transmission 与解析介质路径对照，检查厚度、遮挡、离屏与重复雾化；不代表真实云和粗糙路径已验收 |
| [A3 低分辨率介质有效域](../../sandcastle.html?example=rendering-medium-coverage) | 四个解析介质区间，检查细柱、墙边、地平线、遮挡显露及部分区间查询；不代表真实云或折射验收 |
| [A1 大气与云联合积分](../../sandcastle.html?example=rendering-medium-integration) | 独立后续实验：GPU 解析对照、真实云源项与可选大气源项联合积分、错误串接对照与误差读回 |

A1 案例提供联合参考、错误串接、原方案和吸收权重深度近似四类对照。参考模式支持空气/云开关、T/S 调试视图、32–512 步空气网格与云内 10/5/2 m 最大步长。默认云内 5 m 细化，自动插入云层边界；联合 T 小于 1e-6 时终止。深度近似对云与阴影统一修正球面映射的数值精度，并省去已侵蚀为空的细节采样及默认参数下的恒等幂/零指数项；采样质量和历史资源保持原样，参考参数在这两种模式下禁用。

空气源项可选择直接单次散射或 LUT 有限区间等效源项。后者从 1000 m 区间的已积分 T/S 估算有效源项，每 100 m 更新；这不是空气与云多次散射的完整局部耦合。实验域仍为有限 12 km。

“运行数值检查”覆盖 14 组 GPU 积分解析用例、55 组球面映射精度用例，以及真实介质的 8192 步加边界参考，另列 4096 步差异。参考不提前终止且不缓存空气源项；它使用相同照明近似，不是物理真值。报告还包含纯空气对上游 LUT 的比较、固定稳定映射云样本的合成近似比较（该隔离检查统一关闭 shadow length），并拒绝空白或非有限合成参考。

报告分别提供 CPU 提交、整帧 GPU 时间和额外参考积分 draw 时间，不用后者代表整帧性能。性能验收采用同硬件、场景、分辨率和质量下不低于原方案；单个固定场景的测量不能代表全部组合通过。参考积分修正了球面映射的浮点消减问题，并使用无时序抖动的相机逆投影；吸收权重近似仍是独立候选，不能据此宣称正式管线完成。

已有示例服务运行时，可执行 `node examples/rendering-prototypes/verify-medium.mjs http://localhost:5173 <报告目录>` 复查独立页面和 Sandcastle；脚本不启动服务。性能脚本 `benchmark-medium.mjs <服务> <目录> [noon|sunset|night|above] [--uncapped]` 支持默认帧调度与连续负载两种测量，分别保留结果。下方 9 月 6 日观测保留其原始范围，不代表当前 A1 结论。

建议固定相机后切换合成位置。高斯实验再对比自身空气透视开关，以及近处和远处；远处模型会缩小，可使用相机交互进一步检查。云的运动会影响逐帧比较，不能把不同时间的云像素差异直接归因于合成顺序。可导出 JSON 保存相机、投影、开关与 pass 计数；这些观测不自动判定视觉通过。

原型边界：透明阶段使用独立 HDR 目标，采样不透明深度做遮挡；未实现跨 Spark / OIT / 普通透明对象的统一排序。高斯采用当前栅格深度近似，不是精确体积积分；未验证夜间、云影和全部散射外观参数。云案例旨在证明单张云 overlay 不能直接解决任意透明穿插。案例内部对管线的访问和 shader 适配必须在正式重构中替换为稳定的资源与阶段契约。

高斯样例依赖 Spark 公共资源网络访问。案例卸载会释放实验目标、材质、几何、高斯和 Viewer。

## 本次原型观测（2026-09-06）

Chrome 无头 WebGL 下，三个独立页面和三个 Sandcastle iframe 均已实际运行。分阶段场景观察到透明柱跨地平线完整保留、白墙遮挡正确。高斯 shader 已编译并显示真实 Butterfly；固定默认相机连续两次渲染，切换空气透视使 22,923 个像素发生 RGB 变化，证明分支实际生效，不代表物理准确性已经验收。另检查了 20 km 距离的开关对照。

云场景观察到不透明柱受云遮挡，而大气后合成的透明柱仍覆盖云，证明仅调整顺序不足以实现云穿插。多透明面只是普通 alpha 排序对照，尚未实现跨 Spark/OIT 的统一排序。

源码类型检查、案例入口独立类型检查、8 项相关测试及文档构建通过。示例站生产构建未通过 runner 的 800 KiB gzip 预算：当前为 812.69 KiB；在构建配置中排除新增入口和动态 helper 的对照为 812.49 KiB，同样超限。未调整预算，也未宣称生产站构建通过。

## A3 有效深度实验

A3 使用 0–16 km 的四个解析介质区间，比较全分辨率解析参考、低分辨率完整区间、错误的代表深度截断、覆盖双线性查询足迹的保守截断，以及历史数据缺失时重新生成查询结果。超出 16 km 的查询显示为不可用，不能按真空处理。可切换 2×/4× 降采样与无效查询视图。它验证范围和部分积分规则，尚未连接真实云、相机透视重投影或折射偏移查询。

执行 `node examples/rendering-prototypes/verify-coverage.mjs <服务> <报告目录>`，覆盖独立页、Sandcastle、DPR 1/2、降采样 2×/4× 、奇数读回尺寸和窗口 resize；另比较浏览器实际截图，防止诊断 alpha 污染画布输出。数值读回为线性颜色，不应解释为完整显示空间质量验收。纹理使用 8 个 RGBA32F 附件，报告列出实际尺寸和内存估计；未据此签收生产性能。


## A2 折射介质实验

A2 使用 Three.js `MeshPhysicalMaterial.transmission` 的原生背景采样，并与两个均匀介质层的分段解析路径比较。可调原生光学厚度、IOR、倾角、粗糙度和相机横移；可切换近处遮挡与介质。路径参考采用平行界面、平滑折射和已知世界表面，不是有限实体玻璃侧面的完整追踪，也未连接真实 Takram 云。

原生模式读取已含介质的屏幕背景；错误对照再次施加相机到玻璃的介质，用于暴露重复雾化。有效性视图分别显示离屏、被近处表面遮挡、粗糙路径未支持。粗糙模式的黄色参考是能力标记，其颜色差不是物理误差。纯色零厚度基线单列，避免把棋盘纹理过滤差异误归因于介质。

`node examples/rendering-prototypes/verify-refraction.mjs <服务> <报告目录>` 检查独立页和 Sandcastle。通过表示执行、退化基线及负对照成立，不代表原生近似质量或生产成本达标。实验不会改变正式材质或公开 API。
