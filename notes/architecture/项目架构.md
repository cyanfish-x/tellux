# Tellux 项目架构

> 状态：当前实现导航。2026-09-06 对照 `e849525` 静态核对下述装配、更新和销毁入口；不代表已重新验证所有渲染效果。

公开用法见 [Viewer 文档](../../docs/api/viewer.md)，旧路径转换见 [1.0 迁移指南](../../docs/guide/migration-1.0.md)。本文维护内部职责和容易误判的边界，不复制完整 API 清单。

## 公开门面与内部所有者

`src/index.ts` 是公开 barrel，`src/Viewer.ts` 是组合根。`viewer.tilesets` 是 `SceneTilesetCollection`，与内部 `TilesetManager` 不同；`viewer.renderer` 是 `ViewerRenderer` 门面，原生渲染器从 `.raw` 访问。

| 领域 | 公开入口 | 内部职责与源码 |
| --- | --- | --- |
| 影像 | `viewer.overlays` | [LayerManager](../../src/LayerManager.ts) 管句柄、顺序和样式；变化交给瓦片管理器 |
| 场景 3D Tiles | `viewer.tilesets` | [SceneTilesetCollection](../../src/tiles/SceneTilesetCollection.ts) 对接内部加载、移除与采样失效 |
| 地形与地球 | `viewer.terrain`、`viewer.globe` | [Terrain](../../src/Terrain.ts)、[Globe](../../src/Globe.ts) 对接内部 terrain/surface；隐藏地球通过 `globe.show` |
| 模型、实体、实例化 | `viewer.models`、`viewer.entities`、`viewer.hism` | 各 manager 持有其资源与更新逻辑，由 Viewer 编排生命周期 |
| 相机与交互 | `viewer.camera`、`viewer.controls` | [Camera](../../src/Camera.ts) 使用显式 ellipsoid provider；[ViewerInteractionManager](../../src/controls/ViewerInteractionManager.ts) 管 DOM 交互 |
| 场景状态与时间 | `viewer.scene`、`viewer.clock` | Scene 保存场景用户态；[Clock](../decisions/Clock统一场景时钟.md) 拥有时间，Timeline 与大气是消费者 |
| 输出与高亮 | `viewer.renderer`、`viewer.postProcess`、`viewer.highlighter` | 门面与底层 adapter / manager 分离；不再挂在 `scene.postProcess` / `scene.highlight` |

原生对象出口为 `scene.raw`、`camera.raw`、`renderer.raw`、`globe.raw`。内部类名仍可能沿用 Layer / Tileset 旧称，不能据此恢复旧公开入口。

## 装配与生命周期

[Viewer](../../src/Viewer.ts) 解析配置后创建 renderer adapter、camera、Scene、后处理图和大气，再装配时钟、加载器、瓦片、采样、领域门面、实体、交互、模型和 widgets。WebGPU 的共享后处理图先于大气 manager 创建，使大气及其他 effect 向同一图注册，而不争抢 renderer delegate。

相机通过显式回调获取活动 tileset 的 ellipsoid，不再依赖 `camera.userData.tilesRenderer`。控制器的 ellipsoid 在装配以及地形、影像结构切换后同步。

同步构造期间，可释放资源登记到 `ResourceScope`，失败时逆序回滚；成功后清空回滚栈。`Viewer.create()` 通过 `awaitReadyOrDestroy` 等待 renderer 的异步初始化，失败时完整销毁。直接 `new Viewer()` 的调用方仍需处理异步初始化失败与清理。相关检查位于 [生命周期测试](../../src/test/resourceLifecycle.test.ts)，本次没有重跑测试。

`destroy()` 有重复调用保护：先取消时钟订阅、相机飞行和循环，再释放交互与领域资源、采样任务、后处理 stage、大气与共享图、瓦片、控制器、加载器及 renderer，最后移除 canvas。变更资源归属时同时检查同步构造回滚与正常销毁两条路径，不能只补 `destroy()`。

## 每帧与采样调度

[ViewerRenderLoop](../../src/rendering/ViewerRenderLoop.ts) 持有默认 animation loop、时间差计算及采样 rAF。Viewer 的 `renderFrame` 顺序为：

1. 清理帧缓冲、推进 Clock，同步尺寸与 controls、widgets。
2. 同步 fallback 光照，更新活动地球 tileset 和可见场景 3D Tiles，更新大气光源与自动曝光。
3. 更新模型、HISM、高亮与实体，准备实体和 Symbol 遮挡 pass。
4. 由 renderer adapter 输出场景，再绘制后合成 Symbol。

场景帧结束后，若还有采样任务，render loop 通过下一次 rAF 推进 `HeightSampler`。采样相机用于调度和 raycast，不输出额外离屏画面；关闭默认循环后仍需持续调用 `viewer.render()`。限制和取消语义见 [采样实现链路](sampleHeightMostDetailed实现链路.md)。

## 瓦片、影像与热切换

[TilesetManager](../../src/tiles/TilesetManager.ts) 持有基础 surface、可选 terrain、场景 tileset 注册表、材质插件及采样池。基础 surface 即使有地形也保留，但可见性由地形是否存在与 `globe.show` 决定。

每帧更新的是 terrain 优先、否则 surface 的活动地球 tileset，**以及所有可见的场景 3D Tiles**。不能把“只更新活动地球 tileset”误解为忽略外部 3D Tiles。

创建职责已经拆出：

- [SurfaceTilesetFactory](../../src/tiles/SurfaceTilesetFactory.ts)：裸球生成、表面材质及影像。
- [TerrainTilesetFactory](../../src/tiles/TerrainTilesetFactory.ts)：地形创建和地形影像。
- [ImageryOverlayFactory](../../src/tiles/ImageryOverlayFactory.ts)：source 到上游 overlay/plugin 的适配、透明 fallback。
- [HeightSamplingTilesetPool](../../src/tiles/HeightSamplingTilesetPool.ts)、[TilesetSamplingAdapter](../../src/tiles/TilesetSamplingAdapter.ts)：采样资源复用与上游内部字段隔离。上游字段不是稳定公共契约，升级时局部核对。

影像变化并非一律重建：结构变化取消相关采样并重建 surface / 当前 terrain；排序走 `syncImageryLayerOrder()`；显隐和样式走 `syncImageryLayer()`。地形切换走 `Terrain` 门面，内部重建或移除 terrain、使采样失效并同步控制器。这些路径保留 Viewer、renderer 和 camera 实例。

## 渲染边界与深入阅读

WebGL 使用 `AtmosphereManager`、`PostProcessingManager` 与 `setEffects`；WebGPU 使用 `WebGPUAtmosphereManager` 和单一 `WebGPUPostProcessingManager` 图，Bloom、LensFlare、TAA 各自管理 stage 与资源。后端支持范围查 [当前限制](../../docs/guide/limitations.md)，不能从 WebGL 的能力推定 WebGPU 支持。

- [单一 WebGPU 后处理图决策](../decisions/0003-webgpu-post-processing-graph.md)：解释为何不能让每个 effect 单独接管输出。
- [WebGPU 大数坐标精度](../engineering/WebGPU地球大数坐标精度抖动坑点.md)：`highPrecision` 不替代实例化、骨骼网格的 RTC / 局部原点。
- [局部与地球光照](../decisions/0004-local-vs-globe-lighting.md)、[无法线点云显示色](../decisions/0002-display-referred-point-cloud-colors.md)：区分已经着色的辐射、地表反照率和显示色。
- [Symbol 合成空间](../engineering/Symbol文字发糊与色调映射合成空间坑点.md)：解释后合成绘制与深度保留的原因。
- [知识入口](../README.md)：其他主题与历史评审的按需路由。
