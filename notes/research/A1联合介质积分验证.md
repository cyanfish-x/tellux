## 历史实验记录

## 实现与上游边界

验证版本：Three.js 0.184.0、Takram Atmosphere 0.19.1、Clouds 0.7.6。实验入口为 [rendering-medium-integration.ts](../../examples/rendering-medium-integration.ts)，使用说明见[渲染实验](../../docs/guide/rendering-prototypes.md)。未改变核心引擎或公开 API。

| 取样来源 | 实际使用方式 | 尚未证明的能力 |
| --- | --- | --- |
| Clouds 当前解析后的 `marchClouds` shader | 使用 `sampleWeather`、`sampleMedia` 的局部消光；抽取 `radiance` 乘 `media.scattering` 后、能量积分前的照明代码 | 没有验证可长期兼容升级的公共源项接口；当前依赖具体 shader 文本布局 |
| Atmosphere 的 `ATMOSPHERE` 密度参数、相函数、太阳透射 LUT | 按局部密度计算 Rayleigh/Mie/吸收消光，把每 km 系数换算为每 m；太阳直接照明生成单次散射源项 | 完整多次散射局部源项没有接入，不能将已积分的天空 LUT 值直接当作局部 j |
| 原有云照明 | 保留太阳自遮挡、天空/地面照明、粉末效应及 Tellux 已注入的照明近似 | 未建立空气与云完整的多次散射、遮阴耦合；夜间没有验收 |

具体适配见 [JointMediumMaterial.ts](../../examples/rendering-prototypes/JointMediumMaterial.ts)。候选主函数不调用旧云输出的 `applyAerialPerspective`，在同一视线采样点相加 `sigma` 和 `j` 后积分一次。错误对照分别把整段空气和整段云当成前后相邻段串接；这些对照只用于揭示重叠介质不能如此处理。

原型借用当前云材质的 uniforms 和纹理，先运行原有云/大气 pass 准备资源，再以候选 draw 覆写输出。这是案例取证接缝，既不是生产调度方案，也不是性能优化结果。积分域固定为 12 km，并在每条视线按不透明深度截断；天空远端使用剩余天空背景。域外介质、透明深度切片和折射路径均不在本次实现范围内。

## 数值与画面证据

原始数据：report.json（本地记录：`a1-medium-2026-09-06.json`）。Chrome 152 无头模式、ANGLE D3D11、RTX 3060 Ti，画布 1100×720；固定相机、时钟和云运动。真实介质比较在同一准备帧内执行，局部抖动固定；上游照明准备仍有其自身时间采样状态，不承诺跨次运行逐位相同。

CPU 测试包含解析退化、重叠与相邻段差异、变源项积分收敛。实际 GPU 读回 14 组均匀介质/相邻段解析用例，全部通过，最大绝对误差 `1.066e-6`，阈值 `2e-5`。这只证明积分实现的这些数值性质。

真实场景读回分辨率为 64×36。下面是色调映射前 T（透射率）/S（HDR 散射）的绝对误差；512 步采用相同照明近似，**不是物理真值**。

| 对照 | T p95 / 最大 | S p95 / 最大 |
| --- | --- | --- |
| 联合 64 步 vs 512 步 | 0.01107 / 0.78088 | 0.02334 / 0.15930 |
| 联合 128 步 vs 512 步 | 0.00444 / 0.85119 | 0.01402 / 0.12805 |
| 空气在前串接 vs 联合，均 512 步 | 4.47e-8 / 1.43e-6 | 0.00226 / 0.01446 |
| 云在前串接 vs 联合，均 512 步 | 4.47e-8 / 1.43e-6 | 0.00235 / 0.02581 |
| 纯空气 512 步 vs 上游完整 LUT | 0.00090 / 0.00252 | 0.01950 / 0.02069 |

所有读回均为有限数值。串接的 T 基本相同符合消光积分性质，不能用 T 一致证明 S 正确。64 到 128 步的 p95 改善，但 T 最大误差反而变差；画面也出现薄云漏采和条块状差异，不能宣称已经收敛。纯空气的 S 差异包含单次散射与完整 LUT 的模型差异，不能全部归咎于步数。

额外的 64 步候选 draw 共采样 30 次，GPU p50 为 **13.76 ms**、p95 为 **18.29 ms**，最大 141.03 ms；保留了预热/异常长样本，没有选择性剔除。该计时不包括原有资源准备 pass，也不是整个 Viewer 帧耗时。此轮数据不支持生产性能达标。

## 2026-09-12：稳定映射、参考采样与快速路径补证

本节取代前文“分段只能小幅改善、条带根因未定”的当前状态判断，前面的原始记录与 JSON 保留。正式管线尚未替换，A2/A3 与 B–E 也未完成。

已确认条带来自球面到立方体面的逆变换在面中心附近发生 float32 消减。将 `sqrt(a-sqrt(a*a-6*x*x))` 有理化，避免两个接近数相减；55 组独立正向映射 GPU 用例覆盖近轴、符号与角点。参考 shader 的密度纹理改为显式 LOD 0，并单独使用不带云时序抖动的逆投影，与场景深度 UV 对齐。快速候选只复用稳定坐标变换，保留原有纹理 LOD 策略；云与阴影同时修改。

参考采样采用 64 步空气网格、云层边界与云内最大 5 m 步长。8192 步加边界参考不提前终止、不缓存空气源项，并另测 4096 步，不能称为物理真值。默认空气使用 1000 m LUT 区间估计的等效源项，每 100 m 更新；它保留上游多阶散射近似，但不能证明完整局部多次散射耦合。纯空气对完整 LUT 的 S 最大差异约 0.00115，直接单次散射原方案约 0.0207。夜间、日落和云上俯视均须独立检查。

快速路线使用积分分部恒等式：已有纯空气场景上方的云 overlay 为 `积分(Tcloud*Tair*jcloud ds - Sair dTcloud)`。解析 CPU 退化验证通过。逐云样本查询空气 LUT 的版本代价过大；500 m 前缀插值虽然误差小，但没有获得性能收益。云照明缓存会产生明显局部散射误差，已撤回；保守天气包络和空天气样本提前返回也未测得性能收益。

保留的近似只用云吸收权重估计空气透视深度。原有代表深度还控制薄雾、云影和历史重投影，因此不能直接替换它；最终候选分开统计空气透视深度，保留其余路径。GPU 对照要求候选 alpha 与固定云样本参考一致，空白/非有限参考和 GL 错误都会使检查失败。该合成隔离检查统一关闭 shadow length、统一使用稳定映射；不能将它解释为完整云影传输验收。

性能按用户更正，采用同硬件、场景、分辨率、质量下不低于原方案，撤销 1080p/60 FPS 固定目标。脚本以 ABBA/BAAB 顺序交错采样，每块固定预热 100 帧、保留 60 个整帧 GPU 样本，用唯一帧号防止混入旧阶段。固定场景仍不足以签收全部组合。包含稳定映射的候选目前约 2.32 ms 中位整帧成本，对照原方案约 2.16 ms，仍有回退；不能把早期仅改代表深度的较快数据用于当前候选验收。

复现入口：

`node examples/rendering-prototypes/verify-medium.mjs <示例服务> <输出目录>` 检查独立页与 Sandcastle。

`node examples/rendering-prototypes/verify-medium-matrix.mjs <示例服务> <输出目录>` 检查六组条件。固定场景采样回归上限为 T 最大 0.02、S 最大 0.005，只用于检测当前算法退化，不取代显示空间、遮挡及运动验收。

后续固定样本检查把两个误差来源分开：吸收权重深度相对已经优化的云采样，其 alpha 差异必须为零；恒等幂/线性剖面特化则允许浮点舍入，固定回归限为 HDR/alpha 最大 1e-4、HDR p95 1e-6。这些数值限用于发现数学特化退化，不替代计划中的显示空间质量标准。六组矩阵已通过；本轮最高数学特化 HDR 误差 7.77e-5、alpha 误差 1.93e-5，参数回退误差均为零。

保留的采样优化是在形状侵蚀后密度全零时跳过细节纹理，以及按实际 uniforms 编译恒等天气幂/线性剖面分支。修改 uniforms 后自动清除不再成立的编译条件；非恒等幂、指数剖面、负细节参数的回退已实际 GPU 对比。密度、步长、迭代次数和照明质量设置未降低。此前统一在天气采样后提前返回、以及运行时 uniform 条件分支版本没有收益，已撤回。

分开读回采样计数证实：稳定映射前后天气查询均值接近，但详细密度查询增加约 55%，说明旧坐标误差还影响了详细取样数量。修复坐标以后需要等价计算优化才能抵消这部分成本，不能通过恢复错误坐标来满足性能目标。
