# 无深度场景内容被大气天空分支覆盖坑点

> 2026-09-09：高斯泼溅 3D Tiles 案例中模型被天空“洗白 / 盖住”的排查结论。WebGL `AerialPerspectiveEffect` 天空分支与 `setEffects` HDR 缓冲 clear alpha。

高斯泼溅（Spark `depthWrite: false`）以及同类**写入场景色、但不写深度**的内容，在剪影到天空时会被大气后处理盖住：暗部、门口和草边呈半透明灰蓝，像天空叠在不透明高斯上。这与 [透明实体在地平线被抹掉](透明实体在地平线被大气天空分支抹掉坑点.md) 是同一天空分支，但修复不能把 Spark 挪到大气之后——`SparkRenderer` 必须在场景阶段排序并绘制。

## 现象

`examples/gaussian-splat-3d-tiles.ts` 加载 SvirnasAlyt，开启显示高斯与显示地球：

- 谷仓/草地主体发灰、发“鬼影”，天空色从暗部和软边透出。
- 关闭地球后更明显：模型完全剪影在天空上。
- 不是曝光 / AgX 显示色问题（`SplatColorTransform` 与「保留数据颜色」已处理那条链）。

## 根因

`@takram/three-atmosphere` 的 `AerialPerspectiveEffect` 在 `depth >= 1.0 - 1e-8` 时走天空分支，原先：

```glsl
outputColor.rgb = getSkyRadiance(...);
outputColor.a = 1.0;
return; // 丢掉 inputColor
```

Spark 默认 `depthWrite: false`（半透明核写深度会破坏累加），高斯像素的深度仍是清屏远平面。这些像素被整块换成天空辐射度。

同时 Three.js `WebGLRenderer` 在 `alpha: false` 时 **clear alpha 默认为 1**。`setEffects` 把场景画进 HDR `targetA` 时沿用该值。Spark 预乘混合（`ONE, ONE_MINUS_SRC_ALPHA`）叠在 `a=1` 的目标上，覆盖率 alpha 被焊死为 1，后续无法用 alpha 把高斯叠回天空。

## 修复

1. **天空分支改为预乘 over**：`outputColor.rgb = inputColor.rgb + sky * (1.0 - inputColor.a)`。空像素 `a=0` 仍是纯天空；不透明无深度内容（含暗面）`a≈1` 保留原色。
2. **场景 HDR 缓冲 `setClearAlpha(0)`**（`RendererAdapter` WebGL）。默认画布在 `alpha: false` 时仍不透明；只有内部 HDR 目标露出覆盖率。

高斯案例保持 `depthWrite: false`。给半透明核开深度写入能躲开天空分支，但会把核晕写成硬深度，Spark 文档不推荐。

实体 OIT 仍排在大气之后：它们在主场景阶段被隐藏，不在 `inputColor` 里，天空合成救不了它们。

## 未采纳的替代

- **Spark `depthWrite: true`**：天空分支不再命中，但半透明核写入深度，边缘像硬剪影，且遮挡后续几何。
- **把高斯画在大气之后**：与实体 OIT 同构，但 Spark 依赖场景阶段的排序/绘制，侵入大。
- **用亮度猜测“已有内容”**：暗部与空像素无法区分，正是本症状最重的区域。

## 维护准则

- 不要把 WebGL 场景 HDR 的 clear alpha 改回 1；否则覆盖率丢失，本修复失效。
- 不要为了让大气“看见”高斯就给 Spark 开 `depthWrite`。
- 升级 `@takram/three-atmosphere` 时核对天空分支 hook（`outputColor.a = 1.0;` + `#else // SKY`）仍能打上 over。
- 加性粒子等若把 alpha 写成 1，仍会被当成不透明前景；它们应写覆盖率或排在大气之后。
