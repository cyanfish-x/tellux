# 社区案例展示采用独立 gallery 页 + 首页精选条

社区优秀案例是随时间持续增长的聚合内容，而项目首页是单屏定调的销售叙事，两者诉求冲突；同时案例字段（标题/描述/标签）需要中英双语，而 VitePress 文档站本期不做双语。因此决定把社区案例从首页正文抽离，放入 examples 站的独立 `gallery.html` 子页（复用多入口构建与现有 i18n），首页仅保留「最新 3 条 + 查看全部」的精选条并置于页面底部收尾，空数据时隐藏。

考虑过的替代方案：保留在首页当前中部位置（会打断 workflow 到引擎效果展示的高潮叙事）；放入 docs VitePress 站（无双语能力，语义上文档站也不适合承载作品聚合）；首页完全不露出（社区生态在首页零门面）。这些方案均因上述理由被否。
